# 一本勝負 ～五本で散る頭脳戦～

指の本数を足して、ちょうど5本で相手の手を消す。昔ながらの手遊びに技カードの駆け引きを加えた、和室で正座して戦う頭脳戦です。CPU対戦（3段階）と、1台の端末を渡し合うふたり対戦に対応しています。操作しながら覚えられるチュートリアル付きです。

ブラウザだけで遊べます（インストール不要）。
